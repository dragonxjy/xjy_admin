# 构建体积分析

统计日期：2026-10-21。

本次将全部 JS/CSS 产物从 **3.39 MB 减少至 2.36 MB**，减少 **30.39%**；完整 `dist` 从 **8.09 MB 减少至 7.06 MB**，减少 **12.74%**。

## 统计口径

- 对比优化前、优化后的 Vite `production` 构建，使用相同运行环境和压缩统计脚本。
- 统计 `dist` 中的实际文件，包含所有懒加载页面；这不是首页首次打开时的请求体积，也不是 `node_modules` 的安装体积。
- `1 kB = 1,000 字节`，`1 MB = 1,000,000 字节`。
- gzip 采用 Node.js `gzipSync`、压缩等级 6，逐文件压缩后求和。实际网络传输还取决于服务器的压缩设置与缓存。

## 本次调整

1. **组件和图标按需导入。** 删除入口中全量注册 Element Plus 图标的代码，静态图标交给现有解析器。菜单与面包屑的动态字符串图标保留具名映射，仅引入路由实际使用的 8 个图标。富文本组件与提示 API 也使用自动导入。
2. **组件样式按需加载。** 全量 Element Plus 样式改为基础样式加组件 Sass 入口，继续使用项目的主题变量与界面样式。
3. **缩小图表依赖。** ECharts 只注册工作台使用的折线图、饼图、坐标系、图例、提示框和 Canvas 渲染器。保留原有演示数据、异步组件、尺寸监听与实例销毁行为，恢复原有折线与饼图配色。
4. **移除 animate.css。** 页面、标签和面包屑改用 Vue `Transition` / `TransitionGroup` 淡入，刷新图标通过 Vue 过渡触发。侧栏继续使用 Element Plus 原生展开、收起动画，公共过渡时长集中在 `src/config/public.scss`。
5. **清理未使用的配置和依赖。** 删除未调用的布局工具、旧 CSS 模块变量、无效配置字段，以及未接入的持久化插件和重复的 Mock 构建插件。演示接口继续使用已有 MockJS 实现。未使用依赖的清理主要减少安装维护负担，不能等同于生产包体积收益。

站点、布局、主题色、页面默认值和全局进度条保留集中配置，并为配置项添加注释。首页链接、富文本默认值、消息行为和 HTTP 参数继续保留在各自原来的使用位置。

消息提示使用独立的 `src/styles/message.scss`，底色、文字和细边框随深浅主题切换，使用 `9px` 圆角，通过图标区分状态并支持长文本换行；调用方式与自动关闭时间保留在 `src/Hooks/element.ts`。

公共组件展示页替换原分页器演示，提供消息、通知、确认弹窗和富文本入口；分页器封装仍保留在公共组件目录。页签背景与页面插画直接归属各自页面。主题色支持预设、自定义、恢复默认和本地保存，首页图表使用原有配色。这些调整已包含在本次优化后的体积中。

## 检查与复测

执行 `pnpm check` 检查脚本、样式、Vue/TypeScript 类型并生成生产构建。构建仍会提示 MockJS 内部使用 `eval`、部分依赖块大于 500 kB；这些提示与检查错误分开处理。

重新生成并统计当前构建：

```bash
pnpm build
pnpm analyze:bundle

# 完整字节数与文件明细
pnpm analyze:bundle --json

# 也可统计另存的一份构建目录
node scripts/analyze-bundle.mjs /path/to/previous-dist --json
```

统计脚本仅使用 Node.js 内置模块，未为体积分析增加项目依赖。
